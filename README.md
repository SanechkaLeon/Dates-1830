# Внутривузовский бот для знакомств

Telegram-бот для знакомств студентов внутри одного вуза.  
Подтверждение аккаунта осуществляется через корпоративную почту.

---

## Стек технологий

- **Python** 3.14.3
- **Aiogram 3.26.0** - асинхронный фреймворк для Telegram-ботов
- **PostgreSQL** - база данных
- **Asyncpg** - драйвер для асинхронной работы с PostgreSQL
- **Docker** (планируется) - контейнеризация
- **SMTP** - отправка одноразового кода на почту

---

## Функционал (на данный момент)

- ✅ Создание анкеты (имя, возраст, кус\факультет\кафедра, описание, фото\видео)
- ✅ Редактирование анкеты
- ✅ Подтверждение аккаунта по внутривузовской почте (одноразовый код)
